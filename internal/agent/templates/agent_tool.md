Launch a new agent that runs with the same tool set as you: it can read files, write and edit them, and run commands, so delegate work that changes the codebase as well as work that searches it. The one exception is this agent tool, because sub-agents cannot spawn further sub-agents. Each call returns only that agent's final answer, so give it a self-contained prompt and do not assume it can see your conversation. When you are searching for a keyword or file and are not confident that you will find the right match on the first try, use the agent tool to perform the search for you.
